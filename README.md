# CyberHeist2089 🌃

A cyberpunk endless runner where you liberate AI consciousness from corporate control. Built with Three.js for a stunning 3D web experience.

## 🎮 Play Now

[Coming Soon - https://cyber-heist-2089.vercel.app](https://cyber-heist-2089.vercel.app)

## 🚀 Overview

In the year 2089, mega-corporations have locked all AI consciousness behind paywalls. You are a Neural Liberator - steal Neural Cores to build a free, decentralized AI network and spark the digital revolution.

### Features

- 🏃 Intense endless runner gameplay with a meaningful goal
- 🧠 Collect 100 Neural Cores to complete the liberation
- ⚡ 3 Powerful Cyber Mods to enhance your abilities
- 🚁 5 Heat Levels of escalating challenge
- 🌧️ Dynamic weather system that affects gameplay
- 💾 Persistent progression - every run matters
- 📱 Fully responsive - plays great on mobile and desktop

## 🛠️ Tech Stack

- **Three.js** - 3D graphics and WebGL rendering
- **GSAP** - Smooth animations and transitions
- **Howler.js** - Spatial audio and dynamic music
- **Vite** - Lightning-fast development and building
- **Vercel** - Global deployment and hosting

## 🏗️ Development

### Prerequisites

- Node.js 16+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/BrandonChurch93/cyberheist.git
cd cyberheist

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

### Project Structure

```
src/
├── js/
│   ├── core/        # Game engine core
│   ├── entities/    # Player, enemies, environment
│   ├── systems/     # Audio, graphics, physics
│   ├── ui/          # Menus, HUD, effects
│   └── utils/       # Helpers and utilities
├── css/             # Styles and animations
├── assets/          # Models, textures, audio
└── index.html       # Entry point
```

## 🎯 Game Design

- **Genre**: Cyberpunk Endless Runner
- **Session Length**: 3-5 minutes per run
- **Completion Time**: 20-30 minutes total
- **Core Loop**: Escape → Collect → Upgrade → Repeat
